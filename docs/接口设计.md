## 二、接口详细定义

### 推荐 Recommendations

#### 26. 生成推荐

```
POST /api/v1/recommendations/run?studentId={studentId}
```

**Query 参数**：`studentId`（integer，可选；Demo 无登录态缺省 1001）。

触发一次推荐计算并落库（recommendation_run / recommendation_result）。

**响应 200**：空对象
```json
{ "code": 0, "message": "success", "data": {} }
```

---

#### 27. 查询推荐结果

```
GET /api/v1/recommendations/latest?studentId={studentId}
```

**Query 参数**：`studentId`（integer，可选；Demo 无登录态缺省 1001）。

**响应 200**（线上字段 `directionId/score/rank/confidence` + 增强字段 `name/type/reason`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `results` | array | 推荐方向列表（3-5 个，不足则返回实际数量） |
| `results[].directionId` | integer | 方向ID（career_direction.id） |
| `results[].name` | string | 方向名称（增强字段） |
| `results[].type` | string | 方向类型（增强字段） |
| `results[].score` | number | 匹配度评分（0-1，六维加权 + 霍兰德人格契合度软加分） |
| `results[].rank` | integer | 排序名次 |
| `results[].confidence` | number | 置信度（**归一化概率表达**：对 Top 结果评分做 softmax，0-1，结果集内求和约等于 1；Demo 替代原先 HIGH/MEDIUM/LOW 枚举） |
| `results[].reason` | string | 推荐理由（增强字段，**优先 career-ai 大模型生成，失败回退规则模板**；含霍兰德人格契合与“建议加强”差距提示） |

示例：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "results": [
      { "directionId": 2, "name": "数据科学与算法工程师", "type": "数据算法",
        "score": 0.9765, "rank": 1, "confidence": 0.288,
        "reason": "根据你的兴趣匹配96%、能力匹配95%、发展倾向匹配94%，综合匹配度 95%，你的霍兰德人格类型（R/I/C）与【数据科学与算法工程师】方向契合度 100%，推荐关注【数据科学与算法工程师】方向。建议加强：实践经历。" }
    ]
  }
}
```

> **推荐模块变更说明（2026-08-04 迭代）**
> 1. **差距提示（skill gap）**：评分时计算各维度差距 `gap = max(0, 目标值 - 学生值)/100`，差距达到阈值（10%）的维度在理由中以「建议加强：……」提示（模板文案），不直接淘汰。
> 2. **霍兰德人格类型→方向映射**：`career_direction` 表新增 `personality_tags` 列（RIASEC 编码，逗号分隔）；学生画像快照 `dimension_json` 新增 `personality` 键；推荐评分叠加人格契合度软加分（权重 0.10），契合度按交集 / min(双方数量) 计算。
> 3. **confidence 归一化概率**：由 HIGH/MEDIUM/LOW 枚举改为 softmax 归一化概率（0-1，求和≈1）。
> 4. **接入 career-ai 大模型解释**：推荐理由优先调用 `career-ai`（FastAPI + 大模型，模型名 `deepseek-v4-pro`）的 `POST /v1/recommendation/explain` 生成，失败/超时/未启用时回退规则模板（替换点：`RecommendationEngine.buildReason`）。

#### 28. 推荐反馈

```
POST /api/v1/recommendations/{id}/feedback
```

**Path 参数**：`id`（integer，**可留空**；recommendation_result.id）。留空时服务端自动使用最近一次推荐结果ID（Demo 兜底），填写时建议用示例值 **55**。

**Request Body**（可选）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `feedbackType` | string | 反馈类型：LIKE / DISLIKE / INVALID |
| `comment` | string | 反馈意见 |

**响应 200**：空对象
```json
{ "code": 0, "message": "success", "data": {} }
```

#### 29. 查看最新画像（Demo 补充，线上为准）

```
GET /api/v1/profiles/latest?studentId={studentId}
```

**Query 参数**：`studentId`（integer，可选；线上无此参数，Demo 无登录态故作为增强参数，缺省取 1001）。

**响应 200**（线上定义 `dimensions/summary/version`，Demo 保留增强字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `dimensions` | object | 六维画像：interest/values/academic/ability/orientation/experience |
| `summary` | string | 画像摘要 |
| `version` | string | 画像版本 |
| `completeness` | number | 数据完整度（增强字段） |
| `studentId` | integer | 学生ID（增强字段） |
| `experiences` | array | 实践经历（增强字段） |

学生不存在或画像未生成时返回空对象 `{}`，HTTP 200。

#### 30. AI生成计划草案（Demo 补充，线上为准）

```
POST /api/v1/planning/plans/generate?studentId={studentId}
```

**Query 参数**：`studentId`（integer，可选；Demo 无登录态缺省 1001）。

**数据来源**：调用推荐接口（`/api/v1/recommendations/latest`）的推荐结果，取排名第一的方向作为主目标，并按方向类型套用任务模板生成月度任务。Demo 阶段由规则模板生成（不调用大模型），落库（student_goal / semester_plan / plan_task）后返回草案。

**响应 200**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `studentId` | integer | 学生ID |
| `direction` | object | 推荐方向（来自推荐结果第一名） |
| `direction.directionId/name/type/score` | - | 方向ID/名称/类型/评分 |
| `goal` | object | 目标（student_goal） |
| `goal.id/title/goalType` | - | 目标ID/标题/类型（MAIN/BACKUP） |
| `semester` | string | 学期（semester_plan） |
| `status` | string | 计划状态：DRAFT（草案待确认） |
| `tasks` | array | 月度任务（plan_task） |
| `tasks[].month/title/status` | - | 月份/任务标题/状态（TODO/DOING/DONE/DELAY/ABANDON） |

示例：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "studentId": 1001,
    "direction": { "directionId": 2, "name": "数据科学与算法工程师", "type": "数据算法", "score": 0.9765 },
    "goal": { "id": 1, "title": "以「数据科学与算法工程师」为主攻方向的发展计划", "goalType": "MAIN" },
    "semester": "2026-2027学年第1学期",
    "status": "DRAFT",
    "tasks": [
      { "id": 1, "month": "2026-09", "title": "学习 Python 与数据分析基础", "status": "TODO" },
      { "id": 2, "month": "2026-10", "title": "完成一个数据分析小项目", "status": "TODO" }
    ]
  }
}
```

## 三、通用说明

- **接口前缀**：所有接口统一以 `/api/v1` 开头。
- **参数位置**：入参以 `query` / `path` 参数为主；本 OpenAPI 导出未定义 JSON 请求体。
- **鉴权**：当前导出 `security` 为空（`[]`），实际鉴权方式以 Apifox 线上为准（登录接口返回 `token`）。
- **常用枚举值**（来自文档示例）：推荐置信度 `HIGH` 等；任务状态 `TODO` / `DOING` / `DONE` / `DELAY` / `ABANDON`；发展路径 `POSTGRADUATE`（国内升学）等。
- **文档同步**：Apifox 文档更新后需重新导出 OpenAPI 并重新生成本文档；AI 协作时可通过「刷新接口文档数据」读取最新缓存。
