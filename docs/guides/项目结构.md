# 项目目录结构说明

> 本文件为「生涯规划系统」仓库（`career-planner`）的目录结构总览，供 opencode 制定开发计划、定位文件时参考。
> 记录时间：2026-08-21。仅覆盖仓库内实际有意义的内容，忽略 `.git/`、`node_modules/`、`.venv/`、`target/`、`dist/`、`.playwright-mcp/` 等生成目录。

## `career-ai/` —— FastAPI 智能服务 + AI 网关（Python 3.12）

> 2026-08-29 起：career-ai 升级为**统一 LLM 网关**（`gateway/`，基于 LiteLLM），
> career-core 全量大模型调用经 `POST /v1/chat/completions` 走网关（多渠道路由/重试/降级/rpm 限流，
> 调用日志写 MySQL `ai_call_log`）。

| 路径 | 说明 |
|------|------|
| `api/` | FastAPI 应用包 |
| `api/__init__.py` | 包标记 |
| `api/main.py` | 应用入口（app 创建、lifespan 网关预热、路由注册、统一错误响应） |
| `api/routes_ai.py` | AI 路由定义（聊天/解析/解释/计划/总结等 HTTP 接口） |
| `api/routes_gateway.py` | AI 网关路由（`/v1/chat/completions` OpenAI 兼容、`/api/v1/gateway/generate` 高层入口，GATEWAY_API_KEY 鉴权） |

| `gateway/config.py` | 环境变量 → 渠道凭据/模型组/限流配置 |
| `gateway/client.py` | 统一 `generate()` 入口：Router 多渠道负载均衡 + fallback + 重试 |

### 业务模块（`modules/<模块>/`，每个模块 = controller + dto + entity + mapper + service(+impl) + vo）

| 模块 | 说明 |
|------|------|
| `auth/` | 认证与授权：登录/注册/刷新/改密/重置密码、同意书、白名单、操作审计、token 黑名单 |

| `direction/` | 职业方向探索：方向列表/详情/收藏 |
| `recommendation/` | 方向推荐：推荐运行/结果/反馈 |
| `planning/` | 目标计划：目标/学期计划/任务/打卡/阶段复盘/版本历史/提醒 |
| `advisor/` | 辅导员：学生列表/详情视图/统计/指导评论 |
| `admin/` | 管理后台：能力标签、方向、培养方案课程、模板、权重、白名单、用户、日志、导出、**模型配置、Prompt 版本、问卷管理** |
| `ai/` | AI 集成（2026-08-21 从 career-ai 迁入）：chat/历史/反馈、推荐解释、计划生成、阶段总结、PDF 解析 |

各模块内常见文件命名模式：
- `controller/*Controller.java` — REST 入口，路径 `/api/v1/<模块>/...`
- `dto/*Request.java`（部分为 `DTO`）— 请求参数
- `entity/*.java` — 数据库实体（表 snake_case ↔ 字段驼峰）
- `mapper/*Mapper.java` + `resources/mapper/<模块>/*Mapper.xml` — 数据访问（MyBatis）
- `service/*Service.java` + `service/impl/*ServiceImpl.java` — 业务逻辑
- `vo/*VO.java` — 返回视图对象（`@JsonInclude(NON_NULL)`，空态用默认值）
- `query/*Row.java`（部分模块）— 复杂查询行映射

## 备注（制定计划时注意）

- **前端代码在 `fronted/`（拼写无 e）**；原空壳 `frontend/` 已删除。
- 后端改接口前先对照 `docs/openapi/career-core-apis-live.yaml`（以 Apifox 线上为准）。
- 数据库表结构以 `career-core/src/main/resources/db/schema.sql` 为准（启动幂等执行）。
- AI 能力后端实现在 `career-core/.../modules/ai/`（已迁自 `career-ai/`）；career-core 经 `LlmGateway`（HTTP）全量调用 `career-ai` AI 网关（2026-08-29 起，不再直连 DeepSeek），`career-ai/` 镜像随 CI 单独构建。
- 涉及新增文件时，遵循各模块「controller + dto + entity + mapper + service + vo」分层约定。
