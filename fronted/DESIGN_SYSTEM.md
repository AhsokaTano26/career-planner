# 生涯同行 · 固定设计系统

本项目后续所有页面均以此文档和 `src/styles.css` 中的 CSS 变量为唯一视觉基线。除非产品明确重设品牌，不替换主题、不混用第三方组件默认主题。

## 设计定位

**编辑型生涯档案 / 实验报告工作台**。信息呈现应当直接、可核验、有进度感；用网格、编号、时间与数据表达状态，而非装饰性插画、拟物卡片或泛化的 AI 助手视觉。

## 固定视觉语言

| 元素 | 规则 |
| --- | --- |
| 底色 | 暖灰纸张色 `#F0EFE8`；内容表面 `#FAFAF5`。 |
| 文字 | 主文字 `#171914`，弱文字 `#6F7269`；不使用渐变文字。 |
| 强调 | 荧光绿 `#C7FF38` 表示进行、已确认和可操作状态；橙红 `#FF5C35` 表示重点、进度和提醒。 |
| 边框 | 统一 `1px solid #171914` 或弱分割线 `#C9C9BF`；不使用柔和阴影和大圆角。 |
| 圆角 | 默认 `0`。状态标签、按钮、输入框、信息卡片均保持直角。 |
| 排版 | 标题使用高权重无衬线、大字号、紧字距；状态、编号、元信息使用等宽字体和大写英文微标题。 |
| 图表 | 仅使用线框、纯色数据面、数字和可读的图例；图表颜色遵循主色、荧光绿、橙红。 |

## UI / UX 规则

1. 每个页面标题区必须有英文微标题、中文核心标题和一句解释；标题区以黑色分割线收尾。
2. 页面信息优先以数据表、时间线、步骤条、档案条目或边框网格组织；避免无目的的留白卡片。
3. 每个区域只有一个主要操作，主操作为黑底白字；悬停时可转为橙红。次操作为黑色描边或荧光绿底。
4. 状态必须同时以文字和颜色表达，不能只依赖颜色；完成使用勾选框，进行中使用荧光绿标签，提醒使用橙红。
5. AI 相关内容必须标识为“探索建议”或“智能生成，供探索参考”，不使用拟人头像、气泡卖萌或结论性用语。
6. 信息密度优先于装饰密度；内容块之间使用边框分隔，不使用模糊背景、玻璃态、彩色渐变或悬浮阴影。
7. 移动端保留层级和主要操作：侧栏收缩，网格改为单列，边框和信息编号不省略。

## 禁止项

- 任何二次元角色、作品名称、粉丝站视觉元素或相关素材。
- 渐变背景、玻璃拟态、圆润大卡片、胶囊式主按钮、彩虹色图表。
- 未经设计评审引入 Element Plus 等组件库的默认视觉样式。
- 将荧光绿和橙红同时作为同一控件的常规背景，避免失去状态语义。

## 实施约定

- 新页面先复用 `src/styles.css` 的 `:root` 设计变量；如需新色彩或新组件状态，先更新本文件。
- 新组件至少覆盖默认、悬停、焦点、禁用和移动端状态。
- 保持键盘可聚焦、文字对比足够、图表提供可读标签。
